# Security policy

## Supported versions

CZSH is maintained on the `main` branch. Security fixes are applied to the
latest revision; older snapshots are not supported separately.

## Reporting a vulnerability

Do not open a public issue for vulnerabilities involving command injection,
credential exposure, unsafe downloads, privilege escalation, or destructive
filesystem behavior.

Use GitHub's private vulnerability reporting form instead:

<https://github.com/samastek/czsh/security/advisories/new>

Include the affected platform, the relevant command or configuration path,
reproduction steps, impact, and any suggested mitigation. Remove unrelated
credentials and personal data from all logs.

Non-sensitive hardening suggestions may be submitted as normal issues.
